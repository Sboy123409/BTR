# BTR Roadmap

## Module 1: App Lock
- [x] List installed apps and let the user pick which to lock
- [x] Lock profiles: time windows (e.g. 22:00–07:00), days of week
- [x] Instant locks: lock one app or all apps for a chosen duration
- [ ] Daily usage limits
- [x] Detect the foreground app (AccessibilityService)
- [x] Full-screen block screen
- [x] Emergency unlock that needs a reason + exercise, with history log
- [ ] Motivational message on the block screen
- [ ] "Strict mode": the user can't edit or disable a lock while it is active (partial: locked apps can't be removed from the block list)
- [ ] Permission onboarding (Usage Access, Accessibility, Display over other apps) (partial: Accessibility prompt on Home)
- [x] First-launch welcome screen (BTR poster)

## Module 2: Habit Tracker
- [x] Create and edit daily habits (every day or chosen weekdays)
- [x] One-off to-dos planned for a specific day
- [x] Check-ins and streaks (current + best), week strip to move between days
- [ ] History calendar
- [ ] Reminders/notifications

## Avatar & Home
- [x] Home hub: avatar, today's checklist, App Lock summary
- [x] Comic avatar drawn in code, customisable (face, skin, hair, eyes, brows, outfit, extras, background)
- [x] Avatar mood follows today's progress (sleepy / neutral / happy / ecstatic)

## Module 3: Integration
- [ ] Completing habits earns unlock time
- [ ] Combined daily dashboard (screen time vs. habits)
