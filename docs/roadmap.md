# BTR Roadmap

## Module 1: App Lock
- [ ] List installed apps and let the user pick which to lock
- [ ] Lock profiles: time windows (e.g. 22:00–07:00), days of week, daily usage limits
- [ ] Detect the foreground app (UsageStats / AccessibilityService)
- [ ] Full-screen block overlay with a motivational message
- [ ] "Strict mode": the user can't edit or disable a lock while it is active
- [ ] Permission onboarding (Usage Access, Accessibility, Display over other apps)

## Module 2: Habit Tracker
- [ ] Create and edit daily habits
- [ ] Check-ins, streaks, history calendar
- [ ] Reminders/notifications

## Module 3: Integration
- [ ] Completing habits earns unlock time
- [ ] Combined daily dashboard (screen time vs. habits)
